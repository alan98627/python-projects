# Caesar Cipher

This is a simple Python project that encrypts and decrypts text using the Caesar Cipher technique.

It works by shifting letters in the alphabet by a fixed number. For example, with a shift of 3, "abc" becomes "def".

---

## What this project does

* Encrypts text using a shift value
* Decrypts text back to original form
* Works with both uppercase and lowercase letters
* Takes user input from the terminal
