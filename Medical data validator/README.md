Medical Data Validator

This is a small Python project I made to check if medical patient data is correct or not.

It goes through each patient record and checks things like age, gender, patient ID, and visit ID. If something is wrong, it tells which part is invalid.

What I learned
1. How to work with dictionaries and lists in Python
2. How to split code into multiple files
3. How to use functions properly
4. Basic data validation
5. How to use regex for simple pattern checking

How to run

Just run the main file:
python main.py
